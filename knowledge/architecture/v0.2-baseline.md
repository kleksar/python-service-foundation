# v0.2 template baseline

The template's owner is the Python Service Foundation repository. It owns the narrow generated baseline: FastAPI process setup, standard-library JSON logging, typed environment settings, health endpoints, development quality commands, container packaging, and Copier rendering validation.

Generated-service teams own all application-domain behavior, deployment configuration, credentials, external integrations, data models, and migration content. This foundation is intentionally not deploy ready.

`use_postgres` defaults to true and is a first-party optional profile. It owns only connectivity readiness through `SELECT 1`, async SQLAlchemy/asyncpg wiring, an Alembic skeleton, and local Compose PostgreSQL. With the value false, no database package, import, or runtime dependency is generated. Redis, Taskiq, Sentry, MCP, authentication, and product-domain logic are outside both profiles.

The root `scripts/smoke-template.sh` is the acceptance guard. It renders both profile values and runs the generated project's Ruff, strict Pyright, and pytest checks. Compose configuration is validated where Docker Compose is installed, without starting services or requiring secrets.
